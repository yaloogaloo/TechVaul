为什么有人会包养女大学生？

2026年了，包养并不是罪大恶极

反正我现在跟女大在一起，是要淡化包养这2个字的。我不是要给女大承诺，而是让女大不需要承诺。

经济价值，这是毋容置疑的，但是不能一味的转账，而是要多给体验

每个月给她转帐、交房租。她不会觉得你是在照顾她，而是很简单的觉得你是在包养她。一旦有这个结论后，她就会以一种交易的方式与你相处：我出青春和身体，你出钱，我们就是进行一次交易。大部分女生对这种关系都会感到不正常和羞愧，也会让你很难更进一步

所以我的处理是，不是完全没有转账行为，但是控制次数和金额。把钱花在让她去感受同龄人够不着的生活上，偶尔去吃米其林或者五星级酒店的晚餐，演唱会内场的门票，说走就走的三亚旅行等。给她买她舍不得买的物品包包衣服首饰等，再帮她解决一些其他日常生活中能用钱解决的问题。

转账时不要说给你这个月的生活费，说这些钱你先拿着用。不要让她开口要钱。要在她开口之前就把问题解决掉。记得，她抱怨什么就是暗示需要你买什么，在你预算范围内，该买的买该花的花，转账是最后一步。

情绪价值

交往的情绪价值也很简单，跟她相处的时候把注意力都放在她的身上，眼里只有她，听她说话的时候看着她，不打断，不玩手机。就这种区别于她同龄人的体验对她来说就是稀缺的，稀缺到她会上瘾。

你别评论她的言行举止，不指点她的生活，包容她的穿搭打扮，不批评她的消费观，你不是她爸，你只需要赞同她顺着她就行。管那么多干嘛呢。

很简单的，做好这2点，剩下的就是你向她索取情绪价值和其他价值了。

怎么让她接受这种关系

经济价值和情绪价值供给侧做好之后，就是如何让她从心理上接受这段关系。

如果她问我们之间是什么样的关系，永远不要提包养这2个字，同时也不要用到的词语有：恋人、男女朋友、在一起了这种。当然也不要说什么是好朋友，你们做的事情并不是好朋友会做的，她很清楚。你说是朋友关系她只会觉得你在侮辱智商。就简单的说现在的相处模式我觉得很舒服自在，你觉得怎么样？把问题抛给她。

她要是说“我觉得也挺好的”那默契就形成了，进一步淡化了包养，她也不会感觉受到了冒犯。

关于时间次数

女大和你在一起的时间，不要让她觉得自己是在按次计费，不要固定每周几见面见几次面

有时候给她送一杯奶茶咖啡到学校门口，然后就走。有时候出差或者什么三五天不联系，回来见面时带个小礼物。节奏自己把控，不让她产生我被包养的感觉。自己去多领悟怎么做。

最后一条,让她感觉自己有需要

除了见面和XX，偶尔让她为你做一些小事。比如让她帮你挑衣服，让她给你推荐最近流行的音乐电影，让她教你一些年轻人的梗。只要她也为你付出了某种努力输出了成果，她自己就会在心理上把这段关系合理化：我不是在被他包养，我们是在互相照顾。他对我好，我也对他好。

人天生会为自己的行为寻找合理解释。你只需要创造条件，让她自己得出这个结论就好

所以你看，我哪里是在包养女大学生，我是在跟女大学生正常交往，只是多花了点钱然后这段关系也只有我们2个知道而已。
